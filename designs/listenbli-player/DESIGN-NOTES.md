# listenBli 界面设计稿 — 设计说明

**方向：深夜电台（Midnight Broadcast）**
深色、电影感的音乐播放器。近黑的层叠炭灰取自夜间听歌场景，B 站粉（`#FB7299`）作为唯一的「正在播出」信号色，只用在当前状态上。保留现有三栏结构（顶栏 / 列表 / 歌词 + 底部播放条），把视觉与交互细节做透。

设计尺寸 **1440 × 900**，纯内容区、不带系统窗口外壳；整页以 `transform: scale()` 适配任意视口。

## 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink-1` … `--ink-5` | `#0c0c11` → `#282833` | 底、面板、悬停、浮层，逐层加亮 |
| `--fg` / `--fg-2` / `--fg-3` / `--fg-4` | 白 94% / 66% / 48% / 32% | 主文本 / 次文本 / 元信息 / 装饰 |
| `--accent*` | `#fb7299` 系 | 当前播放、强调、进度条 |
| `--blue` / `--blue-ink` | `#35b6e4` / `#8fd6f2` | 歌词翻译、音质徽章 |
| `--gold` | `#e8c07d` | FLAC 无损徽章 |

**文字对比度**：所有信息性文字在 `--ink-1` 与悬停面 `--ink-4` 上均 ≥ 4.79:1（WCAG AA）。
仅有「已唱过的歌词行」「禁用态按钮」「占位提示行」三类有意压暗；歌词层次为 已唱 `fg-3`(5:1) → 即将唱 `fg-2`(8.6:1) → 当前行 白(19.5:1)。

**字体**：Space Grotesk（拉丁/数字，wordmark、计时）+ Noto Sans SC（界面中文）+ Noto Serif SC（歌词，中文衬线）+ SF Mono（时长、UID、路径）。中文字号行高按 1.6–1.7 放开。

**排版约定**：`--accent` 通过设置面板切换（信号粉 / 霓虹青 / 夜紫）时，四个派生变量同步重算。

## 组件清单

| 组件 | 说明 |
|---|---|
| `TopBar` | 品牌标（播放时三根音柱跳动）、搜索/收藏夹/历史分段控件（未登录显示锁）、`⌘K` 搜索框、无损优先 chip、设置、账号菜单 |
| `ListPane` | 结果头（关键词 + 结果数 + 全部播放）、列头、行列表、收藏夹文件夹 chip 栏、加载骨架、四类空状态 |
| `TrackRow` | 序号、封面（悬停播放/当前均衡器）、标题、作者 + 音质、大会员专享徽章、时长、`⋯`；当前行左侧粉色光条 |
| `LyricsPanel` | 跟随/翻译胶囊开关、来源徽章、自动居中、点击跳转、手动滚动**只暂停居中**（3s 后自动恢复，不改写开关）、逐行氛围光晕 |
| `PlayerBar` | 封面 + 曲目信息、上一首/播放/下一首、可拖动进度条（已缓冲段 = 音频缓存进度）、音量、播放列表浮层、缓存进度行 |
| `StatusBar` | 状态点 + 消息（6s TTL）、音频错误、配置路径 + 复制 |
| `LoginModal` | 生成式二维码（定位符 + 时序图案 + 扫描光带）、已扫码 / 成功 / 过期四态 |
| `SettingsSheet` | 音质、歌词（来源优先级）、外观（强调色/歌词字号/列表密度）、中文字体、配置文件 |

## 歌词跟随的语义（与 Rust 实现一致）

`follow`（用户开关）与 `followPaused`（手动滚动造成的临时暂停）是两个状态：

- 只暂停居中，3 秒后自动恢复；恢复时**不会**改动用户的开关。
- 滚动/拖动只认歌词本体（`onWheel` 挂在歌词容器上），滚动左侧列表不影响歌词。
- 关闭开关后只有用户自己（或「跟随已暂停 · 点击恢复」胶囊）能重新打开；点击歌词行只跳转，不打开开关。

## 已验证的交互状态（14 项，全部通过）

默认播放（歌词居中跟随）· 搜索并播放日文歌（中文翻译）· 无结果 · 大会员专享解析失败 · 未登录收藏夹 · 扫码弹窗 · 二维码过期 · 登录成功解锁收藏夹 · 历史 · 切换文件夹 · 设置面板 · 强调色/字号/密度实时生效 · 无歌词 · 播放列表浮层 + 空格/方向键。

快捷键：`空格` 播放暂停、`←/→` 快退快进 5s、`⌘K` 聚焦搜索、`Esc` 关闭浮层。

## 文件

> `python3 -m http.server 4311 --directory designs` → http://localhost:4311/listenbli-player/ListenBli%20Player.html
